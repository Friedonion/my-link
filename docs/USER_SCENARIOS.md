# 마이링크 (MyLink) - 사용자 시나리오 (User Scenarios)

## 1. 방문자 (Visitor) 시나리오

### 1.1 마이링크 페이지 방문 및 링크 이동
- 사용자는 **특정 크리에이터의 다양한 채널을 한눈에 확인**하기 위해 **인스타그램, 유튜브 등 외부 플랫폼에 공유된 `mylink.com/username` 링크를 클릭**한다.
- 사용자는 **페이지가 열렸을 때 크리에이터가 누구인지 인지**하기 위해 **상단의 프로필 이미지, 이름, 소개글을 확인**한다.
- 사용자는 **원하는 특정 채널(예: 블로그, 쇼핑몰 등)로 이동**하기 위해 **파비콘 아이콘과 제목이 표시된 링크 아이템을 클릭**한다.
- 사용자는 **존재하지 않거나 삭제된 계정인지 확인**하기 위해 **잘못된 주소로 접속했을 시 표시되는 '페이지를 찾을 수 없습니다(404)' 화면을 확인**한다.

---

## 2. 관리자 (Admin) 시나리오

### 2.1 가입 및 고유 주소(Username) 설정
- 사용자는 **마이링크 서비스를 이용**하기 위해 **초기 화면에서 '구글 로그인' 버튼을 클릭하여 회원가입 및 로그인**한다.
- 사용자는 **자신만의 고유한 퍼블릭 페이지 URL을 확보**하기 위해 **최초 로그인 직후 중복되지 않는 영문/숫자 조합의 `username`을 입력하고 저장**한다.

### 2.2 프로필 관리 (인라인 편집)
- 사용자는 **프로필 사진을 변경**하기 위해 **상단의 기존 프로필 이미지 영역을 클릭하여 새로운 사진 파일을 선택 및 업로드**한다.
- 사용자는 **본인의 이름이나 닉네임을 변경**하기 위해 **화면에 표시된 이름 텍스트를 클릭한 후 나타나는 입력창(인라인)에서 내용을 수정하고 저장**한다.
- 사용자는 **방문자에게 보여줄 짧은 소개글을 갱신**하기 위해 **소개글 텍스트를 클릭하여 내용을 수정한 후 저장**한다.

### 2.3 링크 관리 (추가/수정/삭제 - 인라인 편집)
- 사용자는 **새로운 공유 링크를 목록에 배치**하기 위해 **화면 하단 또는 상단의 '링크 추가' 버튼을 클릭하여 비어 있는 새 링크 아이템을 생성**한다.
- 사용자는 **생성된 링크의 내용을 채우고 적용**하기 위해 **빈 링크 아이템의 제목과 URL 영역을 각각 클릭하여 타이핑한 후 포커스를 해제(또는 엔터)하여 저장**한다. (저장 시 URL에 맞는 파비콘이 자동으로 로드되어 표시됨)
- 사용자는 **기존에 등록한 링크의 목적지 주소나 제목을 변경**하기 위해 **해당 링크의 텍스트 영역을 클릭하여 인라인 상태에서 내용을 수정하고 다시 저장**한다.
- 사용자는 **더 이상 유효하지 않거나 필요 없는 링크를 제거**하기 위해 **해당 링크 아이템 측면에 위치한 '삭제(휴지통)' 버튼을 클릭**한다.
